# 🎮 LOOP — اختياراتك بتحكي قصتك

لعبة ويب تفاعلية كاملة باللغة العربية (RTL): ادخل موقفًا خياليًا، خذ سلسلة قرارات
تغيّر الأحداث والنهاية التي تصل إليها، ثم شارك بطاقة نتيجتك وتحدَّ أصدقاءك.

> «قرار واحد ممكن يغيّر كل حاجة»

## ▶️ كيفية التشغيل على جهازك (خطوة بخطوة)

### الطريقة الأولى — الأسرع (من غير أي برامج)
1. حمّل المشروع (من GitHub: **Code ← Download ZIP** وفك الضغط).
2. افتح ملف `index.html` من الفك الضغط بالمتصفح (انقرتين عليه).
3. العب! 🎉 — للعلم: مشاركة الروابط تعمل بشكل أفضل على موقع منشور (HTTP)،
   أما اللعب نفسه فيعمل حتى من فتح الملف مباشرة.

### الطريقة الثانية — خادم محلي (موصى بها)
لو عندك لغة البرمجة JavaScript أداة Node.js:
```bash
npm start
```
ثم افتح في المتصفح: <http://localhost:8000>

بدون Node يأتي مع محرر VS Code إضافة **Live Server**: افتح مجلد المشروع،
انقر بيمين الفأرة على `index.html` ← **Open with Live Server**.

## ✅ تشغيل الاختبارات
فحص آلي يتتبع **كل** مسارات القصة (كل اختيار وكل نهاية) و500 جولة محاكاة لكل تحدى:
```bash
npm test
```
يُفترض أن ترى: «🎉 كل الفحوصات نجحت».

**اختبار متصفح اختياري للمطوّرين** (يفتح اللعبة في محاكاة متصفح، يلعب جولات كاملة
بضغط الأزرار فعليًا، ويختبر المشاركة وإعادة اللعب ومقارنة الأصدقاء):
```bash
npm install --no-save jsdom   # مرة واحدة للتطوير فقط
npm start                     # في طرفية
npm run test:e2e              # في طرفية تانية
```

## 🚀 النشر مجانًا (اختر طريقة واحدة)

### 1) GitHub Pages (الأسهل لو المشروع على GitHub)
1. ادفع المشروع إلى مستودع GitHub.
2. افتح المستودع ← **Settings ← Pages**.
3. في **Source** اختر **Deploy from a branch** ثم الفرع `main` والمجلد `/ (root)` ← **Save**.
4. بعد دقيقة تقريبًا هيظهر رابط موقعك في نفس الصفحة (مثال: `https://USER.github.io/REPO/`).
5. شارك الرابط مع أصدقائك وخلاص!

### 2) Netlify Drop (الأسرع مطلقًا — بدون Git)
1. ادخل <https://app.netlify.com/drop>.
2. اسحب مجلد المشروع كاملًا وأفلته في الصفحة.
3. هتحصل على رابط جاهز في ثوانٍ.

### 3) Vercel
1. ادخل <https://vercel.com> وسجّل دخولك بحساب GitHub.
2. **Add New ← Project** واختر المستودع ← **Deploy** (من غير أي إعدادات Build).

> المشروع «موقع ثابت» بالكامل — لا يحتاج خادمًا ولا بناء (build) ولا مفاتيح API.

## ➕ كيفية إضافة تحدٍّ جديد
المحتوى منفصل تمامًا عن كود الواجهة. في `js/data/challenges.js`:
1. أضف عنصرًا جديدًا في مصفوفة `CHALLENGES` بنفس بنية أى تحدى موجود.
2. كل تحدٍّ يتكوّن من `nodes`: عقد قرار فيها `label` و`text` و`choices`،
   وكل اختيار فيه `next` (العقدة التالية) و`effects` و`result` اختياري،
   والنهاية تكون `ending: true` مع `title/icon/tone/text`.
3. شغّل `npm install`؟ بدون — شغّل `npm test` بس، عشان الاختبارات تتأكد
   آليًا من أن كل مسار يوصِل لنهاية صحية وطوله ٥–٧ قرارات.

مثال مصغّر:
```js
{
  id: 'my-story', title: 'قصتي', icon: '🗺️', tagline: '...', description: '...', minutes: '٣ دقائق',
  start: 'a1',
  nodes: {
    a1: { label: 'البداية', text: '...', choices: [
      { text: '...', next: 'a2', effects: { bold: 2 }, result: '...' },
      { text: '...', next: 'end1', effects: { caution: 1 } }
    ]},
    end1: { ending: true, title: '...', icon: '🏁', tone: '...', text: '...' }
  }
}
```

## ✅ الميزات المكتملة في الإصدار الأول
- واجهة عربية RTL كاملة، داكنة فخمة، متجاوبة مع الموبايل والكمبيوتر.
- **تحديان كاملان**: «قرارك الأخير» (٥ نهايات) و«القطار الأخير» (٤ نهايات)،
  كل جولة ٥–٦ قرارات و٢–٣ اختيارات بمسارات متفرعة حقيقية.
- محرك قرارات مع ٤ متغيرات (الجرأة / التعاون / الحذر / التضحية) ولقب ترفيهي من ١١ لقبًا.
- شاشة نتيجة: النهاية + اللقب + بصمة القرارات + أهم قراراتك.
- مشاركة حقيقية: Web Share API، نسخ رابط، واتساب وتيليجرام، وبطاقة نتيجة كصورة PNG.
- **ومقارنة أصدقاء فعلية بدون خادم**: رابط النتيجة يحمل قراراتك مشفرةً، فمن
  يفتحه ثم يكمل التحدي يرى مقارنة مساريكما (اتفاق/اختلاف وكل منكما وصل أين).
- حفظ تقدم الجلسة محليًا واستكمال اللعب بعد الإغلاق + تحدٍّ يومي يتغير بالتاريخ.
- بدون حساب، بدون تتبع، بدون مفاتيح سرية، بدون أرقام وهمية.

## ⚠️ حدود هذا الإصدار (اقرأها بصراحة)
- لا توجد قاعدة بيانات مركزية: النتائج الجماعية بين أكثر من صديقين في مكان واحد،
  وترتيب اللاعبين (leaderboard)، **غير متوفرة** حاليًا — المقارنة ثنائية عبر الرابط فقط.
- التقدّم يُحفظ على **نفس الجهاز والمتصفح** فقط (تغيير الجهاز = بداية جديدة).
- رابط النتيجة يحتوي قراراتك داخل الرابط نفسه؛ وهو خاص بمن تبعته له — لا يوجد حسابات.

## 🗺️ خطة الطريق المقترحة
1. تفعيل قاعدة بيانات Supabase (بمشروع **مستقل جديد**) باستخدام `supabase/schema.sql`
   لإضافة: غرف أصدقاء برمز، وصفحة مقارنة جماعية، وإحصاءات اختيارية.
2. المزيد من التحديات (البنية جاهزة وقائمتا «قريبًا» معلنتان داخل اللعبة).
3. وضع PWA (تثبيت اللعبة كتطبيق على الموبايل) — أضف `manifest.webmanifest`
   + Service Worker بسيطًا عند الحاجة.
