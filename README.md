# ♾️ LOOP — اختياراتك بتحكي قصتك

لعبة ويب تفاعلية باللغة العربية: تدخل موقفًا خياليًا، تتخذ سلسلة قرارات تغيّر الأحداث التالية والنهاية التي تصل إليها، ثم تحصل على **لقب ترفيهي** و**بطاقة نتيجة قابلة للمشاركة** تتحدى بها أصدقاءك.

> **قرار واحد ممكن يغيّر كل حاجة** 🌀

---

## 🎮 التحديات المتاحة الآن

| التحدي | النوع | النهايات | مدة الجولة |
|---|---|---|---|
| 🌃 **قرارك الأخير** — مدينة كاملة تنطفئ ومصيرها بين يديك | تشويق ونجاة | 5 (منها نهاية سرّية ⭐) | ~٣ دقائق |
| 🏝️ **الجزيرة المنسية** — حطام قارب وثلاثة ناجين في جزيرة مجهولة | مغامرة وبقاء | 5 (منها نهاية سرّية ⭐) | ~٣ دقائق |
| 💸 **مليونير في يوم وليلة** — ربحت ١٠ ملايين فجأة… وبعدين؟ | اجتماعي ومرح | 6 (منها نهاية سرّية ⭐) | ~٣ دقائق |

كل تحدي يحتوي شجرة قرارات خضعت لاختبار آلي شامل: **أكثر من 1600 مسار لعب كامل** تمت محاكاتها للتأكد أن كل مسار (5–7 قرارات) ينتهي دائمًا بنهاية صحيحة، دون تكرار مراحل ودون أي شاشة فارغة.

## ▶️ تشغيل المشروع على جهازك (للمبتدئ)

### ما تحتاجه مرة واحدة فقط
- برنامج **Node.js** (إصدار 18 أو أحدث) — حمّله مجانًا من: https://nodejs.org
- للتأكد أنه تثبّت، افتح الطرفية (Terminal) واكتب: `node --version`

### الخطوات
```bash
# 1) ثبّت الأدوات (مرة واحدة فقط)
npm install

# 2) شغّل اللعبة للتجربة والتطوير
npm run dev
```
ثم افتح في المتصفح: **http://localhost:5173**

> تريد تجربتها على هاتفك في نفس شبكة الواي فاي؟ عند التشغيل سيعرض الطرفية عنوانًا آخر يبدأ بـ `Network:` — افتحه من الهاتف مباشرة.

### اختبار سلامة كل مسارات اللعبة
```bash
npm test
```
هذا يشغّل محاكاة كاملة لكل قرار ومسار ونهاية في كل التحديات، ويطبع تقريرًا بالعربية.

### تجهيز نسخة النشر
```bash
npm run build
```
النتيجة في مجلد `dist` — ملفات ثابتة جاهزة للرفع على أي استضافة (الحجم المضغوط ~40KB فقط!).

## 🌍 النشر مجانًا (اختر أي طريقة)

### ١) Netlify (الأسهل — بدون أوامر)
1. ادخل https://app.netlify.com/drop
2. شغّل `npm run build` على جهازك
3. اسحب مجلد **`dist`** وأفلته في الصفحة — وانتهى! موقعك جاهز برابط فورًا.

### ٢) Vercel
1. ادخل https://vercel.com وسجّل بحساب GitHub
2. اختر **Add New → Project** واستورد هذا المستودع
3. سيتعرف تلقائيًا على Vite — اضغط **Deploy** وسيُبنى وينشر تلقائيًا مع كل تعديل.

### ٣) GitHub Pages
1. ادفع المشروع إلى GitHub
2. من إعدادات المستودع: **Settings → Pages → Build and deployment** اختر **GitHub Actions**
3. اختر قالب *Static HTML* وعدّل خطواته لتشغيل `npm ci && npm run build` ثم رفع مجلد `dist` باستخدام `actions/upload-pages-artifact` مع `path: dist`.

> بعد النشر: أي رابط تشاركه سيعرض تلقائيًا صورة معاينة جميلة في واتساب وتيليجرام (بفضل `public/og.jpg` ووسوم Open Graph).

## ✨ ما المُنفَّذ حاليًا

- ✅ واجهة عربية **RTL** كاملة، تصميم داكن فاخر (بنفسجي × سماوي)، خطوط عربية (Cairo + IBM Plex Sans Arabic)، أزرار كبيرة للمس، ومتجاوبة مع الهاتف والحاسوب.
- ✅ **3 تحديات قصصية كاملة** كتبتُ محتواها بالكامل (قرارات متفرعة، نتائج منطقية لكل قرار، 16 نهاية مختلفة منها نهايات سرّية).
- ✅ **محرك قرارات منفصل عن الواجهة**: المسارات تتغير فعليًا حسب اختياراتك، وبعض الوجهات مشروطة بقيم متغيراتك (الجرأة ⚡، التعاون 🤝، الحذر 🛡️، التضحية 💛).
- ✅ **نظام ألقاب ترفيهي** (11 لقبًا) محسوب من أسلوب لعبك — للمتعة فقط وليس تقييمًا نفسيًا.
- ✅ شريط تقدم، شريط "نتيجة قرارك"، مؤشرات متغيرات مباشرة، سجلّ قرارات كامل في شاشة النتيجة، واختيارات بالكيبورد (1–4).
- ✅ **بطاقة نتيجة تُرسم كصورة** (1080×1350) قابلة للتحميل والمشاركة — بدون أي بيانات شخصية.
- ✅ مشاركة حقيقية: **Web Share API** (مع مشاركة الصورة حيث يدعم الجهاز)، نسخ الرابط، وأزرار واتساب/تيليجرام مباشرة.
- ✅ **مقارنة الأصدقاء عبر الرابط**: رابط نتيجتك يحمل نهايتك ولقبك مشفّرين (`?r=`)؛ صديقك يرى نتيجتك، وبعد جولته تظهر مقارنة «أنت ضد صاحبك» تلقائيًا — كله بدون قاعدة بيانات.
- ✅ **تحدي اليوم** يتبدل تلقائيًا يوميًا، حفظ تقدم الجولة محليًا (أكمل من حيث توقفت)، وتتبّع النهايات التي فتحتها في كل تحدي.
- ✅ **اختبار آلي شامل** (`npm test`) + صفر اعتماديات وقت تشغيل + تعمل دون أي API خارجي، وقابلة للتثبيت كتطبيق (PWA manifest).
- ✅ لا توجد أي أرقام لاعبين أو نسب وهمية — كل الأرقام المعروضة (عدد التحديات/النهايات/إنجازاتك) حقيقية ومحلية.

## 🚀 ما لم يُنفَّذ بعد (خطة تطوير واضحة)

- 🗄️ **قاعدة بيانات مركزية** (مثل Supabase المجاني): نتائج جماعية، "غرف تحدٍّ" برمز قصير، وقوائم مقارنة بين أكثر من صديق — الكود مهيأ لها في `src/lib/storage.js` و`src/lib/share.js` (نفس واجهات الدوال).
- 👤 حسابات اختيارية وملف شخصي ونتائج محفوظة سحابيًا عبر الأجهزة.
- 📅 تحدي يومي "حقيقي" من قاعدة البيانات + إحصاءات مجمّعة حقيقية (لن تُعرض إلا ببيانات فعلية).
- 🔔 إشعارات وتحديات موسمية ولوحة شرف.

## 🧩 كيف تضيف تحديًا جديدًا؟ (الملفات المهمة)

المحتوى منفصل تمامًا عن الواجهة — إضافة قصة جديدة لا تحتاج لمس أي كود عرض:

1. انسخ أي ملف من `src/content/` (مثل `last-decision.js`) وسمّه باسم قصتك.
2. عدّل البيانات: `nodes` للمشاهد والاختيارات، `endings` للنهايات (شرح مفصّل أعلى ملف `last-decision.js`). قواعد مهمة:
   - كل اختيار: `text` و`effects` (أثره على الجرأة/التعاون/الحذر/التضحية) و`next` (مرحلة تالية أو `end:اسم-النهاية` أو مسار مشروط بالمتغيرات) و`echo` اختياري (جملة أثر القرار).
   - اجعل كل مسار كاملًا بين **5 و7 قرارات**، و2–4 اختيارات في كل مرحلة.
3. سجّل التحدي بضبط استيراده في `src/content/index.js`.
4. شغّل `npm test` — سيخبرك إن وجد أي مسار مكسور أو نهاية لا يمكن الوصول إليها.
5. انتهى! سيظهر التحدي تلقائيًا في الصفحة الرئيسية وتتحدث الأعداد وتحدي اليوم من نفسه.

### خريطة المشروع
```
index.html                  ← صفحة الدخول (RTL + وسوم المشاركة)
public/                     ← صورة المشاركة og.jpg + أيقونة + ملف التثبيت
src/
  main.js                   ← واجهة المستخدم والشاشات الثلاث
  style.css                 ← نظام التصميم
  content/                  ← 📚 قصص اللعبة كبيانات (أضف قصصك هنا)
    last-decision.js        ← 🌃 قرارك الأخير
    forgotten-island.js     ← 🏝️ الجزيرة المنسية
    millionaire-day.js      ← 💸 مليونير في يوم وليلة
    titles.js               ← الألقاب وتعريفات المتغيرات الأربعة
    index.js                ← سجلّ التحديات + تحدي اليوم
  lib/
    engine.js               ← 🧠 محرك القرارات (منطق نقي قابل للاختبار)
    share.js                ← تشفير النتيجة في الرابط + روابط المشاركة
    storage.js              ← الحفظ المحلي (نقطة التوسع لقاعدة البيانات)
    card.js                 ← رسم بطاقة النتيجة كصورة
tests/validate.mjs          ← اختبار آلي: كل المسارات والنهايات
```

## 🔒 الخصوصية والأمان
- بدون حسابات ولا تتبّع ولا مفاتيح سرية في الكود.
- البيانات الوحيدة المخزّنة: تقدمك ونتائجك — في متصفحك أنت فقط.
- رابط المشاركة يحتوي فقط: اسم التحدي والنهاية واللقب وقيم لعب (لا شيء شخصي)، والروابط التالفة تُتجاهل بأمان.
